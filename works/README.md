Put each work's images and videos in its own folder here, e.g.

    works/plant-matter/thumb.jpg
    works/plant-matter/01.jpg
    works/plant-matter/clip.mp4

then point to them in js/works.js — the "content" list of each work.
The block types (text, image, video, link, heading) are explained at the
top of js/works.js. YouTube and Vimeo videos don't need a file here: just
paste their link.

Keep videos small (a few MB): GitHub rejects files over 100 MB, and big
files slow the page down. For long videos, upload to YouTube or Vimeo.
